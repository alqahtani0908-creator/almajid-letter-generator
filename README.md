# مولّد خطابات مؤسسة أبناء علي بن عثمان الماجد الأهلية

صفحة تكتب خطابات المؤسسة على الورق الرسمي بخط Brando، وتصدرها ملف PDF برقم تسلسلي (التسلسل/السنة الهجرية).

- التاريخ الهجري يُحسب تلقائياً ويمكن تعديله.
- الترقيم وسجل الخطابات محفوظان في متصفح المستخدم؛ استخدم «تصدير السجل» لأخذ نسخة احتياطية.
